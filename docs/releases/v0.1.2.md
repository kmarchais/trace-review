# Trace Review v0.1.2

Trace Review v0.1.2 renders fenced code blocks correctly in automated review
findings.

## Highlights

- Triple-backtick fences now render as block-level code with preserved line
  breaks and horizontal scrolling.
- Language-tagged fences use the existing theme-aware syntax-highlighting
  pipeline for supported languages.
- Unknown languages and offline reviews degrade safely to escaped plain code.
- Fence language metadata and code contents remain HTML-safe.

## Install

```bash
gh skill install kmarchais/trace-review trace-review@v0.1.2 --scope user
npx skills add https://github.com/kmarchais/trace-review/tree/v0.1.2/skills/trace-review --global
```
