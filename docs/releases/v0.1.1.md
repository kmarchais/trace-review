# Trace Review v0.1.1

Trace Review v0.1.1 fixes inconsistent Markdown rendering in automated review
findings.

## Highlights

- Inline code now renders consistently in both the compact findings list and
  expanded finding cards.
- One HTML-safe renderer handles multiple code spans, longer backtick
  delimiters, emphasis, and multiline finding text.
- Code contents stay literal instead of being reinterpreted as emphasis or
  markup.

## Install

```bash
gh skill install kmarchais/trace-review trace-review@v0.1.1 --scope user
npx skills add https://github.com/kmarchais/trace-review/tree/v0.1.1/skills/trace-review --global
```
