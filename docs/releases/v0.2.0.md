# Trace Review v0.2.0

Trace Review v0.2.0 adds a fast local review command and turns selected diff
ranges into reusable review comments, suggestions, and presentation-ready
exports.

## Highlights

- `bun trace-review` now follows common `git diff` revision forms, writes the
  generated artifacts to `.review/`, and opens the review in a browser.
- Drag-selecting a contiguous diff range can create a comment, a
  GitHub-compatible suggested change, or an export containing both sides.
- Diff exports support side-by-side and compact layouts, syntax coloring,
  editable PowerPoint tables, selectable HTML, SVG, and PNG.
- PowerPoint exports preserve indentation, use dense Office-safe rows, and
  offer optional presentation background presets.
- Module TypeScript and common extension aliases, including `.mts`, receive
  language-aware syntax highlighting.
- Deterministic workspace reviews no longer present their grouping order as an
  AI-suggested reading order.

## Install

```bash
gh skill install kmarchais/trace-review trace-review@v0.2.0 --scope user
npx skills add https://github.com/kmarchais/trace-review/tree/v0.2.0/skills/trace-review --global
```
