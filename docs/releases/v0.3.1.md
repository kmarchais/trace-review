# Trace Review v0.3.1

Trace Review v0.3.1 sharpens generated review metadata and makes changed-token
emphasis more accurate.

## Highlights

- Review headers now include the local generation time when no explicit
  `generated` label is supplied.
- Changed tokens use background highlighting without an additional underline.
- Uneven replacement blocks match deleted lines to structurally related added
  lines instead of pairing them with newly inserted comments or statements.

## Install

```bash
gh skill install kmarchais/trace-review trace-review@v0.3.1 --scope user
npx skills add https://github.com/kmarchais/trace-review/tree/v0.3.1/skills/trace-review --global
```

## Validation

- The complete repository checks and release bundle validation pass.
- A regression fixture covers a deleted statement followed by inserted comments
  and a related replacement statement.
- Tagged installer checks run in the release workflow before publication.
