# Trace Review v0.1.0

Trace Review turns a working-tree diff, branch range, or pull request into a
self-contained interactive HTML review. This first public release gives coding
agents a bounded two-command path while keeping heavy patch evidence on disk.

## Highlights

- Whole-file views for every diff file, including SVG image and code modes.
- Workspace, LM-analysis, and explicit deep-audit review modes, with `lm`,
  `ai`, and `pr <number>` shortcuts.
- One structured model result between `prepare` and `finish`.
- Decision-oriented change groups with dependency-aware reading order.
- Unified and split diffs, persistent comments, orphan recovery, progress, and
  Markdown export.
- Native GitHub review publication with an explicit preview and confirmation.
- A zero-dependency compiled runtime requiring Node 22+ and Git.
- Release-only cross-agent installation through GitHub CLI, the `skills` CLI,
  or a minimal ZIP.

## Install

```bash
gh skill install kmarchais/trace-review trace-review@v0.1.0 --scope user
npx skills add https://github.com/kmarchais/trace-review/tree/v0.1.0/skills/trace-review --global
```
