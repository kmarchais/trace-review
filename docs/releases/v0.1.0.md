# Trace Review v0.1.0

Trace Review turns a working-tree diff, branch range, or pull request into a
self-contained interactive HTML review. This first public release keeps heavy
patch evidence on disk while giving coding agents a compact, validated workflow
for semantic grouping and optional LM findings.

## Highlights

- Workspace, LM-analysis, and explicit deep-audit review modes.
- Decision-oriented change groups with dependency-aware reading order.
- Unified and split diffs, persistent comments, orphan recovery, progress, and
  Markdown export.
- A zero-dependency compiled runtime requiring Node 22+ and Git.
- Standard cross-agent installation plus a minimal release ZIP.

## Install

```bash
gh skill install kmarchais/trace-review trace-review@v0.1.0 --scope user
npx skills add https://github.com/kmarchais/trace-review/tree/v0.1.0/skills/trace-review --global
```

GitHub CLI and manual ZIP installation are documented in the
[project README](../../README.md#install).
