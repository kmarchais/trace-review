# Trace Review v0.3.0

Trace Review v0.3.0 makes large and parallel reviews safer to navigate, easier
to act on, and simpler to reset.

## Highlights

- Generated reviews use descriptive, collision-safe filenames, including when
  parallel sessions finish at the same time.
- The header can clear all review-specific comments, attachments, viewed state,
  finding decisions, and grouping choices after confirmation.
- LM findings are concise, may include a concrete code replacement, and offer
  short response options tailored to the finding.
- Reply is now a persisted choice that can be selected alongside a finding
  response.
- Large reviews add search, combinable filters, first-match navigation, and
  responsive indexing across hundreds of files.
- Adaptive repeated-change detection isolates related transformations while
  preserving full change coverage and deterministic validation.
